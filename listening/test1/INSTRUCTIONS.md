# Прослуховування: реальне піаніно чи синтетичне? (~5 хв)

Дякую, що допомагаєш!

1. **Відкрий посилання**, яке я надіслав (просто тапни — воно відкриється у браузері, телефон або комп'ютер). Найкраще в навушниках, у тиші.
2. Для кожного з **30 кліпів** (одна нота, ~3 с) послухай і обери:

   | | |
   |--|--|
   | **1** | точно **реальне** акустичне |
   | **2** | скоріше **реальне** |
   | **3** | скоріше **синтетичне** |
   | **4** | точно **синтетичне** |

3. Унизу натисни **«Завершити»**.
4. **Надішли мені результат:** натисни **«📤 Поділитися»** (вибери Telegram/пошту) — або **«📋 Копіювати»** і встав рядок у відповідь мені. (Кнопка «⬇️ Завантажити CSV» — якщо зручніше файлом.)

**Важливо:** тут **немає** 50/50 — суди кожен кліп окремо, довіряй першому враженню, ні з ким не радься.
